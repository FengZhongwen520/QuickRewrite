# QuickRewrite

**选中即改写，有框即落地。**

QuickRewrite 是一款常驻 Windows 系统托盘的 AI 文本改写工具。它不绑定某个应用：在微信、浏览器、Word、邮件、Notion、IDE 里选中一段文字，按 `Ctrl+Alt+R`，选择改写方式，预览结果，再一键替换回原处；也可以复制结果，粘贴到任何支持粘贴的输入框。

> **凡可选择文字的位置，均可改写；凡有输入框的位置，均可复制。**

## 两个核心能力

### 1. 选中即改写，有框即落地

QuickRewrite 工作在系统层，不要求应用提供插件或 API：

- **改写**：在任意可选中文字的应用里选中一段文字，按 `Ctrl+Alt+R`，选择模式，预览后点“确认改写”，结果会替换原选区并重新选中。
- **复制**：点“复制结果”把改写后的文字放进剪贴板，再粘贴到聊天框、邮件正文、搜索框、表单、文档等任何支持粘贴的输入框。
- **不打断工作流**：工作台只出现一个窗口，选模式后右侧原地生成；点击窗口外自动关闭。

```text
任意应用选中文字
        │  Ctrl+Alt+R
        ▼
  选择改写模式
        │
        ▼
  预览改写结果
     ┌──┴──┐
     ▼     ▼
 确认改写  复制结果
 回填原处  粘贴到任意输入框
```

受系统权限和控件实现限制，终端、密码框、提权应用、远程桌面和部分自绘控件可能无法读取选区；这类场景请参考“当前限制”。

### 2. 多种模式，适配多种场景

同一个工具，不同场合需要不同的说话方式。

| 模式 | 一句话 | 最适合 |
| --- | --- | --- |
| 智能改写 | 保持原意，整体优化表达 | 不确定选哪个模式时 |
| 更友好 | 降低攻击性，增加礼貌和缓冲 | **友好应对同事**：催进度、提异议、拒绝、跨部门协作 |
| 更专业 | 结构清晰、术语准确、少口语 | **专业应对 AI**：写提示词、正式邮件、方案、汇报 |
| 更简洁 | 去冗余，保留结论和关键信息 | **简洁理解原文**：长文、会议纪要、聊天记录 |
| 校对优化 | 修正错别字、语病、标点 | 发布前最后检查 |
| 自定义指令 | 按你的要求改写 | 固定风格、格式、角色、长度 |

> 记住三个最常用的搭配：**友好应对同事，专业应对 AI，简洁理解原文。**

#### 友好应对同事

把“必须”“赶紧”“不行”这类硬表达，改成有边界但不伤和气。适合催进度、提异议、拒绝请求、跨部门协作。

> 原文：这个今天必须给我，不然我这边没法推进。
>
> 更友好：方便今天帮忙确认一下吗？我这边后续排期需要用到，辛苦啦。

#### 专业应对 AI

把口语化需求整理成角色、任务、约束和输出格式清楚的提示词，让 AI 更少猜、更快给出可用结果。

> 原文：帮我写个新品介绍，发公众号。
>
> 更专业：你是一名资深品牌文案。请为以下新品撰写一篇公众号推文，面向 25～35 岁的都市用户，语气克制、有画面感；输出标题 3 个、正文 600 字左右，结尾附一句行动号召。产品信息如下：……

#### 简洁理解原文

先让长文变短，快速抓住结论、动作项和关键数字；也可以把简洁结果直接发给同事，减少来回确认。

> 原文：关于本次活动的执行安排，我们原计划在本周三完成物料终稿，但由于设计资源冲突，时间需要顺延到本周五；上线时间不变，仍为下周一，预算维持不变。
>
> 更简洁：物料终稿顺延至本周五；下周一按原计划上线；预算不变。

以上为示意，实际输出取决于所用模型和你的自定义指令。

## 30 秒上手

1. 运行安装包，QuickRewrite 会常驻系统托盘。
2. 在任意应用中选中一段文字。
3. 按 `Ctrl+Alt+R`。
4. 选择改写模式，等待右侧生成结果。
5. 点“确认改写”替换原选区，或点“复制结果”粘贴到输入框。
6. 替换后 10 秒内可点“撤回改写”恢复原文。

默认快捷键是 `Ctrl+Alt+R`，可在设置中修改。第一次使用可以留在演示模式，不需要 API Key；演示模式只做轻量本地替换，用来熟悉交互。

## 安装

运行安装包即可，无需管理员权限，也无需预装 .NET：

```powershell
dist\QuickRewrite-Setup-1.0.0-x64.exe
```

- 默认安装到 `%LOCALAPPDATA%\Programs\QuickRewrite`，按当前用户安装。
- 安装包已内置 .NET 10 运行时，目标机器无需单独安装。
- 支持 Windows 10 1809+ / Windows 11 x64。
- 安装时可选择“登录 Windows 时自动启动”（默认勾选）和“创建桌面快捷方式”（默认不勾选）。
- 卸载入口在 Windows 设置 → 应用 → 已安装的应用 → QuickRewrite；卸载会自动结束后台进程，并可选择是否同时删除配置和日志。
- 静默安装：`QuickRewrite-Setup-1.0.0-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`。
- 安装包暂未做代码签名，首次运行可能出现 SmartScreen 提示，选择“更多信息 → 仍要运行”即可。

## 配置真实 AI 服务

打开设置，选择“OpenAI 兼容接口”，填写：

- `Base URL`，例如 `https://api.openai.com/v1` 或 `https://api.deepseek.com/v1`
- `模型名称`，例如 `gpt-4o-mini` 或 `deepseek-chat`
- `API Key`
- `超时（秒）`
- `最大输入字数`，默认 5000，可设置 100～50,000

当前使用 OpenAI 兼容的 `/chat/completions` 接口。中文输入输出中文，英文输入输出英文。开启低思考快速模式后会缩短提示词，优先降低响应延迟。

## 可靠性与隐私

- 演示模式不联网，适合先体验交互。
- 使用 API 模式时，选中的文字会发送到你配置的 AI 服务。
- API Key 使用 Windows DPAPI 加密后保存在本机。
- 运行日志位于 `%LOCALAPPDATA%\QuickRewrite\logs\app.log`，只记录运行状态和异常堆栈，不记录选中文字或 API Key。
- 配置文件原子写入；文件损坏时自动备份并回退默认设置。
- 单实例运行；重复启动会唤起已运行实例的设置窗口。
- AI 请求兼容回退：第三方接口不接受扩展参数时自动改用最小请求体；429/5xx 有限重试。
- 生产版本建议将 AI 请求放到服务端代理，避免客户端直接持有长期 API Key。

## 当前限制

- MVP 仅支持 Windows。
- 富文本格式暂不完整保留，当前按纯文本写回。
- 暂不支持流式输出，长文本需要等待完整响应。
- 开机启动目前只能在安装时选择，设置内还不能切换；菜单顺序自定义和历史记录尚未实现。
- 安装包仅提供 x64 版本，且暂未做代码签名。
- 仅支持 OpenAI 兼容的 Chat Completions 协议，不支持各厂商原生 SDK 协议。
- 终端、密码框、提权应用、远程桌面和部分自定义控件可能不支持选区读取或写回。
- 浏览器和 Electron 应用优先使用剪贴板兜底读取。
- 演示模式只做轻量本地替换，用于验证交互；真实改写质量需要配置模型服务。

## 开发与打包

构建、测试和运行：

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\run.ps1
```

打包安装程序：

```powershell
.\scripts\package.ps1
```

脚本会依次运行冒烟测试、发布 `win-x64` 自包含版本并调用 Inno Setup 编译安装包，产物在 `dist/`：

- `QuickRewrite-Setup-<版本>-x64.exe`
- `QuickRewrite-Setup-<版本>-x64.exe.sha256`

可选参数：

- `-SkipTests`：跳过冒烟测试
- `-SkipPublish`：复用 `.package\publish` 中已有的发布结果，只重编安装包
- `-Version 1.2.0`：临时指定版本号（默认读取 `QuickRewrite.csproj` 中的 `<Version>`）

打包环境需要 .NET 10 SDK 和 Inno Setup 6.5+（可用 `winget install -e --id JRSoftware.InnoSetup --scope user` 安装）。首次发布需要联网还原运行时包。

技术栈：

- .NET 10
- WPF
- Win32 全局快捷键
- Windows UI Automation + 剪贴板兜底读取选区
- 剪贴板 + 模拟粘贴写回原文
