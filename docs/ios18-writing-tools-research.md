# iOS 18 AI 文本改写调研（Writing Tools）

> 调研日期：2026-11-06  
> 目的：为“任何可输入文字的位置都能唤起快捷改写菜单”的产品需求提供参考基线。

## 1. 一句话结论

iOS 18 的 Writing Tools 不是一个孤立的改写页面，而是嵌入系统文本编辑链路的“选中文本 → 选择意图 → 预览结果 → 替换/复制 → 撤销”的完整闭环。它真正值得借鉴的是交互闭环和低打扰设计，而不只是几个改写按钮。

## 2. 官方能力范围

根据 Apple iOS 18 使用手册：

- Writing Tools 可用于校对、改写、调整语气、总结所选文本，以及从零撰写内容。
- 它出现在“大多数可以写作的地方”，包括第三方 App 和网站。
- 入口通常有两个：
  1. 选中文本后，通过编辑菜单进入 **Writing Tools（写作工具）**；
  2. 点击键盘右上角的 Writing Tools 入口。
- 处理对象默认是“选中的文本”，而不是自动读取整个文档。
- 处理结果先作为新版本呈现，用户确认后才替换原文；可切换原文/结果、重新生成、恢复原文。

## 3. iOS 18 的改写选项

### 3.1 改写与语气

- **Rewrite / 改写**：重写选中文本，改善表达。
- **Friendly / 友好**：改写为更友好、亲切的语气。
- **Professional / 专业**：改写为更正式、专业的语气。
- **Concise / 简洁**：压缩表达，保留核心信息。
- **Describe your change / 描述你的修改**：用自然语言提出自定义要求，例如“让语气更热情”。

### 3.2 校对

- **Proofread / 校对**：检查语法和拼写错误。
- 修改处用发光下划线标记。
- 用户可以查看每一项修改及解释、忽略单项修改、在原文和修改版之间切换，或整体恢复原文。

### 3.3 总结与结构化

- **Summarize / 总结**：生成摘要。
- **Key Points / 要点**：提炼为要点。
- **List / 列表**：把原文整理成列表。
- **Table / 表格**：把原文整理成表格。
- 结果支持复制、替换和分享；源文本不可编辑时不提供“替换”。

### 3.4 从零撰写（依赖 ChatGPT 扩展）

- 在 Writing Tools 中可进入 **Compose / 撰写**。
- 用户描述想写的内容，并可选择“包含全部文本”或“仅包含选中文本”。
- 该能力依赖 ChatGPT 扩展，受地区、语言、年龄和账号条件限制，不属于 iOS 18 基础改写闭环的必选能力。

## 4. 交互闭环

```text
选中文本
  ↓
唤起 Writing Tools
  ↓
选择改写意图（改写 / 语气 / 校对 / 自定义…）
  ↓
生成结果并预览
  ↓
切换原文 / 结果、重新生成、恢复
  ↓
复制 / 替换 / 分享
  ↓
完成或撤销
```

关键特征：

1. **入口贴近编辑现场**：不跳转独立编辑器。
2. **先预览后生效**：默认不破坏原文。
3. **结果可逆**：随时切换原文、恢复原文。
4. **意图是预设的**：用户不必每次写提示词。
5. **保留用户控制权**：替换、复制、分享由用户主动选择。
6. **处理范围明确**：默认只处理选中内容。

## 5. 对我们的启示

### 应该借鉴

- 选中文本后一键唤起，不要求用户先复制到另一个页面。
- 首屏只放高频意图，低频能力后置。
- 默认“改写”，同时提供友好、专业、简洁等语气快捷项。
- 结果必须可预览、可重试、可复制、可替换、可撤销。
- 处理失败时绝不破坏原文。
- 保持原文的事实、数字、专有名词和段落结构。
- 支持一条自然语言自定义指令，解决预设覆盖不了的需求。

### 不应直接照搬

- iOS 可以在系统层面深度接入几乎所有文本控件；Windows 第三方应用通常无法把自己的菜单注入所有 App 的原生右键菜单。
- 因此桌面端 MVP 更现实的入口是：**全局快捷键 + 浮层菜单 + 剪贴板/辅助功能读写 + 模拟粘贴**。
- 若产品只服务网页，浏览器扩展可以做到更原生的“输入框旁悬浮按钮/右键菜单”，可靠性也更高。

## 6. 桌面端需要特别处理的差异

| 维度 | iOS 18 Writing Tools | 桌面第三方工具的现实约束 |
|---|---|---|
| 入口 | 系统级文本菜单/键盘入口 | 全局快捷键最稳定；原生右键菜单难以全覆盖 |
| 读取选区 | 系统文本编辑框架直接提供 | UI Automation 优先，剪贴板复制兜底 |
| 替换文本 | 系统编辑框架内完成 | 写回剪贴板并模拟粘贴，需处理焦点和失败回退 |
| 撤销 | 系统原生可逆 | 应用内“撤销替换”叠加目标 App 的 Ctrl+Z |
| 富文本 | 系统可处理一定程度格式 | MVP 建议按纯文本处理，富文本作为后续能力 |
| 安全 | 系统可识别安全输入区域 | 需主动排除密码框、终端和不确定控件 |
